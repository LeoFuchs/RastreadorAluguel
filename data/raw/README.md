# Dados brutos

Este diretório armazena os dados coletados do Quinto Andar.

## Estrutura esperada

```text
data/raw/
└── quintoandar/
    └── vila_mariana/
        └── YYYY_MM_DD/
            └── quintoandar_vila_mariana_YYYY_MM_DD.csv
```

Os arquivos são organizados por bairro e data. Os bairros vêm das configurações em `src/config.py`.

# Dados do projeto

Este diretório reúne os arquivos gerados pela coleta do Quinto Andar, pelo comparador e pela curadoria.

- `raw/`: coletas do Quinto Andar por bairro e data.
- `processed/`: anúncios novos por bairro, comparados com as coletas disponíveis dos sete dias anteriores.
- `curated/`: resultados diários da curadoria, fila de URLs pendentes e registro das URLs concluídas.

Os arquivos de dados tabulares usam formato CSV. Os caminhos são relativos à raiz do repositório.

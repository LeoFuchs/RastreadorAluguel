# Dados do projeto

Este diretório reúne os arquivos gerados pelos coletores e pelo comparador.

- `raw/`: uma coleta por plataforma, bairro e data.
- `processed/`: diferenças entre as duas datas mais recentes de cada plataforma e bairro.

Os arquivos usam uma coluna `URL` e são gerados em CSV. Os caminhos são relativos à raiz do repositório.

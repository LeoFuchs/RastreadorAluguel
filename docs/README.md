# Documentação de código

Este diretório reúne documentação complementar que não pertence ao guia rápido do projeto.

## Pontos importantes

- Os coletores usam Selenium e dependem do Google Chrome.
- O Quinto Andar carrega resultados com o botão `Ver mais` e interrompe quando a quantidade de cards deixa de aumentar.
- Os links do Quinto Andar podem usar `/imovel/` ou `/classificado/`; a categoria é preservada na normalização.
- O comparador calcula a diferença entre as duas datas mais recentes de cada combinação de plataforma e bairro.

Novos fluxos, decisões de arquitetura e instruções operacionais podem ser documentados aqui.
